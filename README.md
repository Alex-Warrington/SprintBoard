# SprintBoard
A full-stack team project management application inspired by tools like Jira.

# Technologies
- C#/ASP.NET Core for backend
- TypeScript/React for frontend

# How to run
1. Clone the repository
2. Run 'dotnet run' in the backend folder
3. Run `npm install` in the frontend folder
4. Run `npm run dev` in the frontend folder

# How do I know it's working?
Open the frontend in the browser on "http://localhost:5173/" and make sure it is displaying the message "The SprintBoard API is running!"
